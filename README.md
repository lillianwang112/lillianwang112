<h2>What I've Built</h2>

<h3>📖 <a href="https://lillianwang112.github.io/chinese-learning-app/">汉语学习 — Chinese Learning App</a></h3>

> A full-featured Chinese vocabulary app built for Princeton's CHI 108 — because Quizlet wasn't cutting it.

**900+ vocab cards** across 25 topic decks. SM-2 spaced repetition, handwriting practice with animated stroke order, an AI tutor that grades practice tests (小考, quizzes, essays), configurable quizzes, cloud sync, and six study modes. Single-file React PWA with 238 commits and counting. Free, ad-free, open source.

<h3>⌨️ <a href="https://github.com/lillianwang112/neurotyper">NeuroTyper</a></h3>

> A neuroscience study tool disguised as a typing race.

Paste in lecture passages and race against adaptive bots named after neurotransmitters (Glutamate, Dopamine, GABA, Acetylcholine) that scale to your WPM. Tracks accuracy, speed, and history — all local, no backend.
